
セットアップ手順

前提：
該当PCへパイソンPython 3.11.2以上の環境がインストールされpythonコマンドがDOSで使用可能な状態である事

1.aoc-mgzのサイトからaoc-mgzのgitリポジトリを取得しローカルへクローン
https://github.com/happyleavesaoc/aoc-mgz/tree/56337a6034a0c4d573561ed9614d81dfcdf20824

2.展開したルートディレクトリにてDOSコマンドプロンプトを開きpython setup.py installを実行してaoc-mgzのソースコードのビルドと実行形式ファイルをパイソン環境へ登録

3.本ツールを実行し左上のファイル一覧よりファイルを指定して実行ボタンを押下しデータが表示されていることを確認
